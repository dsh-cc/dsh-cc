## 1. Context

dsh-cc consumes ~64 `@deepseek-ai/*` packages through `link:` devDependencies
and `>=0.1.1-rc.2` peer ranges. Five breaking surface changes must be absorbed:

1. **`packages/client/runtime` removed** (be531688f3). Consumer:
   `packages/interaction/command-permissions` imports `ClientContext`,
   `ISessions`, `SessionFace` from `@deepseek-ai/dsh-client-runtime/client`.
   Replacements verified at the pin: `ClientContext` = cordis `Context`;
   `ISessions`/`SessionFace` live in `@deepseek-ai/dsh-api-session-controller/client`.
2. **`packages/subagent/tool-subagent-report` removed with no replacement**
   (merge b91e7ce366; preceded by ec493c2db8 steer-unification). Consumers:
   `packages/bundle/cc-shell`, `packages/subagent/task` (links + composition
   tests), `packages/subagent/coordinator` (doc/prompt contract).
3. **Value utilities extracted to NEW package `@deepseek-ai/dsh-util-values`**
   (`packages/util/values`, 0.1.3-alpha.2): `JsonValue`, `isJsonValue`,
   `snapshotJsonValue`, `deepFreeze`, `assertNever`, `deepEqualJson`. `dsh-llm`
   and `dsh-session` no longer re-export them.
4. **`CallId` renamed to `ToolCallId`** in `dsh-llm` (a789637db6; constructor now
   uses `brandString` instead of identity cast). Ripples into dsh-cc's own
   `ToolExecution.callId` type — a dsh-cc public-type change.
5. **Pure helper exports removed:**
   - `dsh-settings`: `settingsNamespace()`, `installSettingsSection()` → type-level
     constraint (`SettingsNamespaceInput`) + `SettingsProvider.installSection()`
     method (index.ts:472). `SettingsNamespace` type and `SettingsSectionHooks`
     still exported. persist/publish/watcher contract otherwise unchanged
     (settings hot-reload safe; treated as unverified-by-reviewer, smoke-tested).
   - `dsh-plan-mode`: `foldPlanMode()` → session projection `plan`.
   - `dsh-sandbox-policy`: `effectiveSandboxMode()` → projection `sandboxMode`;
     `setSandboxMode`/`SANDBOX_MODES` unchanged (session-mode.ts exports both
     at the pin).

Also: `cc-serena-first/package.json` links the never-existent
`packages/agent/agent` (broken even at baseline) → fix to `packages/core/agent`.

Non-goals: adopting upstream web/sidebar features; re-plumbing dsh-cc onto
upstream projections for reads dsh-cc already folds (see §5 rationale); any
harness checkout source modification (read-only directive — `pnpm build:lib`
writes only gitignored `lib/`, verified `.gitignore:4`, allowed).
