# @dsh-cc/acp

English | [中文](README.zh.md)

Agent Client Protocol (ACP, v1) server that lets an ACP client (e.g. Zed) drive dsh-cc agents over JSON-RPC on stdio. This package is a verbatim vendor of `@deepseek-ai/dsh-acp` (`packages/acp/acp`, deepseek-harness, MIT — see `LICENSE-harness`), pinned at `c1b47e41fcd54d20a0f061df28683bfc29ee24e5`; every ported file carries a provenance header and CC-specific divergences must be recorded in `DIVERGENCE.md`. The vendoring and extension plan is described in `docs/plans/2026-10-09-acp-m2-own-plugin.md`.
