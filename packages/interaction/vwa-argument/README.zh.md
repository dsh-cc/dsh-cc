# @dsh-cc/vwa-argument

VWA 第二层基础：严格的作者／审查／收据 Schema、项目存储、证据快照、论证图、依赖追踪、正文绑定和冻结的审查配置。

本包尚未挂载到 VWA preset。插件仅注册设置，不暴露作者／审查工具、`/vwa` 命令或交付服务，语义审查默认关闭。交付 PR 将接入用户入口。

设计见 `docs/plans/2026-10-16-vwa-evidence-argument.md`。定义 Schema 不代表语义正确性或人工校准已经完成。

## 审查引擎

现已提供来源／支持／主张／论证四阶段审查、全文抽取与对齐审计、保守评级、当前输入身份校验、分歧保留、统一模型调用预算和可恢复的用量记账。npm 包包含提示词资源。测试在 provider 边界使用假模型；人工校准准确率和真实模型验收仍待完成。

插件仍仅注册设置，工具、命令、采集监听、报告、收据和 preset 挂载由交付 PR 接入。
